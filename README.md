
# RAG-Based AI Teaching Assistant

**Project Status:** In Progress 🚧

## Overview
A Retrieval-Augmented Generation (RAG) based AI Teaching Assistant that answers questions about educational videos using their content.

## Current Features
- Audio and video processing
- Speech transcription using Whisper
- Text chunking for retrieval
- Semantic embeddings using Sentence Transformers
- Exploration of semantic search and context-aware question answering

## Tech Stack
- Python
- Whisper
- Sentence Transformers
- Pandas
- RAG

## Project Structure
- `process_video.py` — Video processing
- `stt.py` — Speech-to-text processing
- `chunks_create.py` — Text chunking
- `read_chunks.py` — Reading and inspecting chunks

## Current Progress
The transcription and text chunking workflow is under development. Retrieval, question answering, and application integration are planned improvements.

## Future Improvements
- Complete the retrieval and generation pipeline
- Improve timestamp-aware retrieval
- Build an interactive user interface
- Evaluate answer relevance and accuracy
